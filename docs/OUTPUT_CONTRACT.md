# 输出契约

五件套固定文件名、固定章节。任何产物缺章节都视为运行失败。

## 一致性规则（最重要）

```
04_简历风险点.md 中的每条风险点都有编号 R-01, R-02, ...
        │
        ├─→ 01_面试对话实录.md 中，面试官追问该点时标注 [R-01]
        ├─→ 02_复盘报告.md  中，该题评分扣分理由引用 [R-01]
        └─→ 05_改后简历     中，每处改动在改动说明里引用 [R-01]
```

没有这条链，四份产物就是四份互不相关的文档，价值减半。

---

## 1. `01_面试对话实录.md`

| 章节 | 必需内容 |
|---|---|
| 面试信息 | 岗位、轮次、面试官人设、时间 |
| 逐轮对话 | 面试官提问 → 候选人回答 → 追问链（标注层次） |
| 标记 | `[R-xx]` 风险点关联、`⚠️ 编造/错误` 标记、`🔴 答不住` 标记 |
| 结尾 | 候选人反问环节 |

## 2. `02_复盘报告.md`

| 章节 | 必需内容 |
|---|---|
| 评分表 | 逐题：维度、得分（1–5）、扣分理由（引用原话）、关联风险点编号 |
| 分轮汇总 | 每轮均分 + 趋势 |
| 追问链评估 | 哪些追问答住了、哪些崩了 |
| 雷区命中 | 对照 `rubric/red_flags.md` 的命中项 |
| 编造检测 | 逐条列出与事实不符的表述 |
| 总评 | 加权总分、通过概率判断、最大风险 Top3 |
| 改进项 | 可执行动作（话术/材料/知识补强），按优先级 |

## 3. `03_薪资建议.md`

| 章节 | 必需内容 |
|---|---|
| 结论 | **区间**（下限 / 中位 / 上限），不给单点值 |
| 推理链 | 逐项：JD 区间 → 年限/资历定位 → 能力匹配度 → 城市系数 → 谈判空间 |
| 依据声明 | 每项依据来自哪里；无出处的市场数据**不得出现** |
| 报价策略 | 首报多少、如何应对压价、底线在哪 |
| 不确定性 | 明确说明哪些因素无法评估 |

## 4. `04_简历风险点.md`

| 字段 | 说明 |
|---|---|
| 编号 | `R-01` |
| 类型 | 事实错误 / 数字不实 / 张冠李戴 / 编造 / 措辞注水 / 口径缺失 / 时间线 / 夸大词 |
| 严重度 | 🔴 一票否决 / 🟠 高 / 🟡 中 / ⚪ 低 |
| 可验证性 | 可验证 / 可佐证 / 仅叙述 |
| 原文 | 简历原句 |
| 问题 | 为什么会被问倒 |
| 改写建议 | 可直接替换的文案（不新增事实） |

## 5. `05_改后简历.html` / `.pdf`

| 要求 | 说明 |
|---|---|
| 保留事实 | 只修表述、口径、结构；不新增无法自证的内容 |
| 通用性 | 默认不绑定单一岗位（去岗位绑定是用户明确要求） |
| 改动说明 | HTML 顶部有改动清单，**打印时自动隐藏**，不进 PDF |
| 打印规范 | A4、无页眉页脚、分页保护（标题不孤立页底） |
| 编号回溯 | 改动说明中逐条引用 `R-xx` |
