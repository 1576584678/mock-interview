# Java 开发工程师 · 供应链履约（仓储物流）

**薪资范围**：20K – 35K ｜ **工作地点**：杭州 ｜ **经验要求**：3–8 年

## 岗位职责

1. 负责供应链履约域（仓储、物流）后端系统的设计、开发与线上问题定位；
2. 参与出库、波次、面单、运费结算等核心链路的需求评审与方案设计；
3. 承接大促保障，参与容量评估、压测与限流降级预案；
4. 推动现有系统的性能优化与稳定性治理。

## 任职要求

1. 本科及以上学历，3 年以上 Java 后端开发经验，Java 基础扎实；
2. 熟练掌握 Spring Boot、MyBatis 等主流框架，理解 IoC / AOP 原理；
3. 熟悉 MySQL，具备索引优化、慢查询分析与事务隔离级别的实践经验；
4. 熟悉 Redis，理解常见数据结构与缓存穿透 / 击穿 / 雪崩的应对方案；
5. 熟悉消息队列（Kafka / RocketMQ），理解消息可靠投递与幂等消费；
6. 有限流、降级、熔断的实践经验；
7. 有良好的问题定位能力，能独立排查线上 CPU、内存、GC 问题；
8. 熟悉分布式事务常见方案与最终一致性设计。

## 加分项

1. 有仓储、物流、履约类业务系统经验；
2. 熟悉 MySQL 分库分表、读写分离、数据一致性方案，了解 TiDB / MyCAT 者优先；
3. 有 K8s、容器化部署与 CI/CD 实践经验；
4. 有大数据量场景下的性能调优经验（单表亿级）。
