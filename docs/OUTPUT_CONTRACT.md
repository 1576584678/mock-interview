# 输出契约

五件套固定文件名、固定章节。任何产物缺章节都视为运行失败。

## 一致性规则（最重要）

```
04_简历风险点.md 中的每条风险点都有编号 R-01, R-02, ...
        │
        ├─→ 01_面试对话实录.md 中，面试官追问该点时标注 [R-01]
        ├─→ 02_复盘报告.md  中，该题评分扣分理由引用 [R-01]
        └─→ 05_改后简历     中，每处改动在改动说明里引用 [R-01]
```

没有这条链，四份产物就是四份互不相关的文档，价值减半。

---

## 1. `01_面试对话实录.md`

| 章节 | 必需内容 |
|---|---|
| 面试信息 | 岗位、轮次、面试官人设、时间 |
| 逐轮对话 | 面试官提问 → 候选人回答 → 追问链（标注层次） |
| 标记 | `[R-xx]` 风险点关联、`⚠️ 编造/错误` 标记、`🔴 答不住` 标记 |
| 结尾 | 候选人反问环节 |

## 2. `02_复盘报告.md`

| 章节 | 必需内容 |
|---|---|
| 评分表 | 逐题：维度、得分（1–5）、扣分理由（引用原话）、关联风险点编号 |
| 分轮汇总 | 每轮均分 + 趋势 |
| 追问链评估 | 哪些追问答住了、哪些崩了 |
| 雷区命中 | 对照 `rubric/red_flags.md` 的命中项 |
| 编造检测 | 逐条列出与事实不符的表述 |
| 总评 | 加权总分、通过概率判断、最大风险 Top3 |
| 改进项 | 可执行动作（话术/材料/知识补强），按优先级 |

## 3. `03_薪资建议.md`

| 章节 | 必需内容 |
|---|---|
| 结论 | **区间**（下限 / 中位 / 上限），不给单点值 |
| 推理链 | 逐项：JD 区间 → 年限/资历定位 → 能力匹配度 → 城市系数 → 谈判空间 |
| 依据声明 | 每项依据来自哪里；无出处的市场数据**不得出现** |
| 报价策略 | 首报多少、如何应对压价、底线在哪 |
| 不确定性 | 明确说明哪些因素无法评估 |

## 4. `04_简历风险点.md`

| 字段 | 说明 |
|---|---|
| 编号 | `R-01`（在 P2 追问目标、P3 评分、P5 改动之间共享，**编号一经分配不得变动**） |
| 类型 | **硬性门槛**（年限/学历不满足 JD 硬条件）／**时间线**／**口径缺失**／**能力缺口**／**夸大词**／**机制存疑** |
| 严重度 | 🔴 必改 / 🟠 必须准备 / 🟡 建议改 / ⚪ 无需准备 |
| 可验证性 | 可验证 / 可佐证 / 仅叙述 |
| 原文 | 简历原句 |
| 问题 | 为什么会被问倒 |
| 改写建议 | 可直接替换的文案（不新增事实） |
| 代码验真（P4） | 命中的验真条目 `E-xx 判决／可见性`；无仓库时为 `—` |

**排序规则**：有验真结果时按**面试可见性**排序（当场可判 → 追问可判 → 需材料才可判 → 不可判），
其次按严重度；无验真结果时按严重度排序。

**章节**：一、清单 ｜ 二、改写建议 ｜ 三、代码/git 验真清单（P4）｜
四、面试前必做（只收"当场可判 / 追问可判"**且确有问题的**）｜ 五、闭环校验。

**红线**：代码里查不到某机制、提交数对不上 —— 属于"需材料才可判"，只能写"建议改成真实数字"，
**不得写成造假**。判编造的唯一入口是面试实录（P3）。

## 5. `05_改后简历.html` / `.pdf`

| 要求 | 说明 |
|---|---|
| 保留事实 | 只修表述、口径、结构；不新增无法自证的内容 |
| 成对替换 | 每处改动都是 `replace_from`（必须在原文中逐字命中）→ `replace_to`；引入新数字 → 整份拒绝 |
| 通用性 | 默认不绑定单一岗位（去岗位绑定是用户明确要求） |
| 改动说明 | HTML 顶部有改动清单，**打印时自动隐藏**，不进 PDF（导出后反查确认 0 泄漏） |
| 打印规范 | A4、无页眉页脚、分页保护（标题不孤立页底） |
| 编号回溯 | 改动说明中逐条引用 `R-xx` |
| 人工闸门 | `--pdf` 必须同时给 `--confirm`；`--verify-pdf` 可出验证件 |

## 6. `out/evidence.json`（P4 验真层）

| 字段 | 说明 |
|---|---|
| `taken_at` / `author_filter` | 取证时点；git 作者过滤（同一人多邮箱会漏统计，需用户确认） |
| `repos{alias:{path,branch,head}}` | 取证仓库的分支与 HEAD commit |
| `readonly_verified` | 取证前后分支/HEAD 一致才为 true（只读保证） |
| `claims[]` | 每条：`id`(E-xx) / `kind` / `claim_text` / `expected` / `observed` / `verdict` / `visibility` / `severity` / `is_fabrication` / `method` / `command` / `evidence` / `risk_ids` |
| `verdict` | 可信 / 存疑 / 与事实不符 / 无法验证（**四档**） |
| `visibility` | 当场可判 / 追问可判 / 需材料才可判 / 不可判（**决定严重度**） |
| `is_fabrication` | 本层**恒为 false**；只能由面试实录（P3）置位 |
| `summary` | 分布统计 + `must_fix` / `must_prepare` / `verified_ok` / `no_prep_needed` / `fabrications` |
